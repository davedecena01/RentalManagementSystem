# Wave 4 — PDF Generation Design

**Date:** 2026-05-10
**Scope:** On-demand PDF generation for lease agreements and payment receipts
**Library:** QuestPDF (MIT license, free)

---

## Overview

Two PDF document types generated on demand by the backend and previewed in dedicated Angular preview pages. No storage involved — PDFs are streamed per request.

| Document | Backend Endpoint | Preview Route |
|---|---|---|
| Lease Agreement | `GET /api/leases/{id}/pdf` | `/leases/:id/pdf-preview` |
| Payment Receipt | `GET /api/payments/{id}/receipt` | `/payments/:id/receipt-preview` |

---

## Backend

### Dependency

Add `QuestPDF` NuGet package to `RentalManagementApi.csproj`.

### PdfService

New service at `Application/Services/PdfService.cs`.

**Methods:**

```
GenerateLeasePdf(Guid leaseId, Guid requestorId) → byte[]
GeneratePaymentReceiptPdf(Guid paymentId, Guid requestorId) → byte[]
```

Each method:
1. Loads the entity from the DB with required navigation properties
2. Validates the requestor has access (ownership or tenant association)
3. Builds the QuestPDF document and returns `byte[]`
4. Throws `UnauthorizedAccessException` if access denied, `KeyNotFoundException` if not found

### Endpoints

**LeaseController** — add action:
```
GET /api/leases/{id}/pdf
[Authorize]
→ File(bytes, "application/pdf", "lease-agreement.pdf") with Content-Disposition: inline
```

Access: landlord who owns the property on the lease, OR the tenant assigned to the lease.

**PaymentsController** — add action:
```
GET /api/payments/{id}/receipt
[Authorize]
→ File(bytes, "application/pdf", "payment-receipt.pdf") with Content-Disposition: inline
```

Access: same rules as `GET /api/payments/{id}`.

### PDF Content

**Lease Agreement:**
- Header: app name ("Rental Property Manager"), generation date
- Section: Property — name, address, type
- Section: Parties — landlord name (from property owner), tenant name, tenant email
- Section: Lease Terms — start date, end date, monthly rent, deposit amount, advance amount, status
- Section: Signatures — two-column placeholder block (Landlord signature / date, Tenant signature / date)
- Footer: "This document was generated electronically."

**Payment Receipt:**
- Header: "Payment Receipt", receipt reference (last 8 chars of payment ID uppercased)
- Section: Property — name, address
- Section: Tenant — name, email
- Section: Payment Details — due date, amount due, amount paid, balance, status badge text
- Section: Payment Date — date paid (if status is Paid or Partial), notes (if any)
- Footer: "Generated by Rental Property Manager on {date}"

## Frontend

### New Components

**LeasePdfPreviewComponent**
- Route: `/leases/:id/pdf-preview`
- File: `features/leases/lease-pdf-preview/lease-pdf-preview.component.ts`

**ReceiptPreviewComponent**
- Route: `/payments/:id/receipt-preview`
- File: `features/payments/receipt-preview/receipt-preview.component.ts`

### Component Behavior (both)

1. On init: call the backend endpoint with `responseType: 'blob'`
2. Create an object URL: `URL.createObjectURL(blob)`
3. Sanitize with `DomSanitizer.bypassSecurityTrustResourceUrl(objectUrl)`
4. Bind to `<iframe [src]="safeUrl" ...>`
5. On destroy: call `URL.revokeObjectURL(objectUrl)` to release memory
6. States: loading spinner, error message (404 / 500), iframe (success)

### Component Template Layout

```
← Back to [Lease / Payments]

[Page title]

[Loading... / Error message / <iframe>]

[Download PDF button]  ← triggers <a [href]="objectUrl" download="filename.pdf"> click
```

### Triggers

**Lease detail page** (`lease-detail.component.html`):
- Add button: "View Lease PDF" → `routerLink="/leases/{{lease.id}}/pdf-preview"`

**Payments list** (`payments-list.component.html`):
- Add button per row: "View Receipt" → `routerLink="/payments/{{payment.id}}/receipt-preview"`
- Only show when payment status is `Paid` or `Partial`

### ApiService additions

```typescript
getLeasePdf(id: string): Observable<Blob>
  → this.http.get(`${base}/leases/${id}/pdf`, { responseType: 'blob' })

getPaymentReceipt(id: string): Observable<Blob>
  → this.http.get(`${base}/payments/${id}/receipt`, { responseType: 'blob' })
```

## Authorization Summary

| Action | Landlord | Tenant |
|---|---|---|
| View lease PDF | Owner of property on the lease | Assigned to the lease |
| View payment receipt | Owner of the lease the payment belongs to | Tenant on that lease |

Backend enforces both. Frontend shows buttons regardless of role (backend returns 403 if unauthorized).

---

## Error Handling

| Scenario | Backend | Frontend |
|---|---|---|
| Entity not found | 404 | "Document not found." message |
| Unauthorized | 403 | "You don't have access to this document." |
| Generation failure | 500 | "Failed to generate document. Please try again." |
